## Clips (`clips/`)

Each clip is a GIF (1280 px wide, for the README) and an MP4 (1920×1080, H.264, for posts and video sites). Long waits are sped up; nothing else is edited.

| Clip | Length | Shows |
| ---- | ------ | ----- |
| `agent-turn` | 30 s | A prompt to add a 5-day forecast strip; Clara reads the project, edits six files and summarises |
| `turn-review` | 16 s | Opening each edited file as a before/after diff of that turn |
| `theme-proposal` | 28 s | Asking for a synthwave theme and previewing it across the app |
