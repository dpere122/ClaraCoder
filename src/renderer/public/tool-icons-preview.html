Tool icons & spinners — draft

One glyph per tool. At rest it is the icon (16 / 20 px); in a live pill the same glyph animates as that tool's spinner (24 px, and 64 px on the left).

Glyphs use the app-tool-spinner tones: --t-primary line work, --t-secondary highlights, --t-hljs-number third tone. Reduced motion freezes every spinner on its icon frame. lsp_update_*_file / lsp_create_*_file share the Write glyph; unknown and MCP tools fall back to the plug.
